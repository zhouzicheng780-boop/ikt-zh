# IKT 地下基础设施研究院 · 中文网站

德国 IKT（Institut für Unterirdische Infrastruktur，盖尔森基兴）官网的中文版本。
纯手写静态站点：HTML + CSS + 少量原生 JavaScript，无框架、无构建步骤。

## 页面

- `index.html` 首页
- `ueber-uns.html` 关于我们
- `forschung.html` 研究
- `warentest.html` 产品测评
- `pruefstelle.html` 检测中心
- `seminare.html` 研讨培训（含课程筛选/检索）
- `netzwerke.html` 合作网络
- `downloads.html` 下载中心

## 本地预览

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

- 页面图片引用自原站 www.ikt.de 的公开资源。
